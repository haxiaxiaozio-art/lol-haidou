# 玩家偏好网页更新

更新日期：2026-09-10。仅更新网页，数据助手继续使用 0.6.0、V17 协议，不更新安装器或网络估算服务。

## 功能与口径

首次进入默认玩家检索，展示待查询状态，不载入演示数据。保留本机客户端查询和同步、战报库、JSON 备份恢复，移除演示检索、CSV 导入和模板下载入口。常驻运营端账号查询暂缓，不索取 QQ 密码、验证码或客户端令牌。

最爱英雄按出场数、最爱海克斯按携带场次确定，并列时明确标记，不以胜率强行裁决最爱。统计以比赛 ID 去重，ID 优先归并名称；旧占位名称里的严格数字 ID 也可归并，歧义名称不强制合并。数据范围展示起止日期与有效比赛数。

个人海克斯选用率是携带场次除以海克斯字段可用场次，同一局同一海克斯只计一次。缺失标记和空槽记录不补零、不进入分母。每局多海克斯，选用率合计可能大于 100%。没有候选池记录，不能解释成刷出后的选择概率。

携带胜率为携带时胜场除以携带场次。正式胜率榜至少 10 局，按未取整的胜率排序，同胜率按场次，再按名称和 ID；低样本在选用率表中保留数字和提示。每页 30 项，名字或编号搜索针对全部条目，不只当前页。

趣味总结为本地确定性文案，附真实计数，最多三条。单一英雄至少出场三局才给常玩描述，单一海克斯至少五局才给常带描述；顺风搭配必须达到胜率榜门槛且胜率超过 50%。并列或样本不足直接说明，不编造段位、性格、候选选择或因果收益。

## 恢复与失败处理

JSON 恢复必须有玩家身份、schemaVersion 1、非演示来源和可解析对局，最多 500 场、5 MB。海克斯和装备列表分别限制 16 项，每项 120 字符；保留海克斯空槽、质量缺失标记、评分引擎和历史时间。文件读取完成前若离开战报库，任务失效，不覆盖后来打开的战报。旧演示记录不默认删除，折叠管理入口可逐份移出以释放容量。

没登录、没助手、同步失败或没有海斗记录时显示对应状态，不以演示数据兜底。查询失败保留上一份战报并明确提示。个人统计不新增外部网络请求。

## 验收

1. 首次打开没有虚构玩家、评分和比赛，演示与 CSV 页签已移除。
2. 同步 20、40、100 或 200 场，核对战报身份、实际筛选海斗场数、偏好范围。
3. 选两枚已知海克斯，按对局详情手算携带场次、胜场、选用率；切到胜率榜确认不足 10 场不入榜。
4. 用名称和编号搜索，超过 30 项时翻页确认没有丢失条目；手机可在表格内横向查看全部列。
5. 导出并恢复 JSON 后，身份、时间、评分引擎和偏好数字一致；缺失字段仍缺失。
6. 在白天、深夜模式及手机宽度验收排版。测试用合成记录不随正式首页展示。

验证命令：`npm run lint`、`npm test`、`npm run export:pages`。发布至现有 GitHub Pages；助手、数据库和评分版本不变。回滚网页提交即可恢复原入口，浏览器旧记录格式不迁移、不删除。
