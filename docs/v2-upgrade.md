# 海斗战报 V2 升级边界

更新：2026-09-10。目标是可解释的复盘工具，不是官方隐藏分或全服实力排名。

网页：[海斗战报](https://haxiaxiaozio-art.github.io/lol-haidou/)。助手增强版：0.6.0，协议继续兼容 V17，不提高网页最低协议版本。只有重新同步或导入包含新字段的 JSON 才能得到历史文件里原本缺失的队伍占比。单份导入最多 500 场、5 MB；战报库最多 10 位玩家，避免主线程评分被超大文件阻塞。

## V2 评分

70 分表示规则基线水平。输出、控制、保护、承伤、经济效率与参战维度按英雄特征分配权重。经济占比仅作资源分配描述，不直接奖励吃经济；承伤结合死亡负担，不能靠送头刷分。缺失指标移出权重，并收缩至中性基线，标记数据不足。

同英雄、同补丁、相近时长（±25%）、排除本场并按 ID 去重的个人历史作为参考。至少 5 场才启用，每项至少 5 个有效值；中位数按 n/(n+20) 收缩，最高占基准的一半。样本来自当前战报，不代表全服。

副职业仍然只加分，不参与均分；只奖励高于 70 分的额外表现，上限 6 分。没有副职业不会扣分。普通死亡为小权重；确有回城时间线时，后续死亡加重且正向表现权重降低。未获得时间线不能靠海克斯名称猜测死亡时间。

V2 固定版本号，与旧版社区职业模型分开。导出记录所选引擎；旧报告仍可用旧版回放。尚未完成跨玩家真实样本校验，所以界面明确标为试算。

当前专属规则覆盖：莫甘娜、萨勒芬妮、阿卡丽、维克托、奥恩、金克丝、亚托克斯、阿利斯塔、蕾欧娜、诺提勒斯、派克、索拉卡。其他英雄使用明确标注的通用职业规则，不能宣称全英雄都完成专属校准。新增英雄规则或修改权重时必须提升评分规则版本，并维护旧版本回放策略。

## 常驻查询服务的接入条件

所需正式凭据：允许服务端查询国服 Riot ID、对应大区、比赛列表及详情的授权，并明确缓存、展示、查询他人和限流条款。网站与本机 SGP/LCU 是不同权限边界，不能把本机会话搬到公共服务器。

建议服务契约：`GET /api/players/lookup?region=&gameName=&tag=&limit=20|40|100|200`，响应包含 `status`、`source`、`fetchedAt`、`expiresAt`、`dataset`。状态区分 `provider-unavailable`、`not-found`、`cached`、`fresh`、`rate-limited`。缓存键含大区和完整 Riot ID，短时合并请求，限流，授权密钥仅放服务端 Secret。当前未接入此接口，不能显示“云端已接入”。

后续：授权提供商适配、经同意的云端战报存储与删除、跨玩家英雄/版本/海克斯样本校准、实时队友字段完整性监控、辅助装备特例、可选英雄表现时间线。
